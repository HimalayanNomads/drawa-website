Your coding agent's work, drawn as a map.

Drawa is a canvas workspace for coding agents, Claude Code, OpenCode, Codex and Antigravity. Run several sessions side by side, watch every file they read, edit and run appear wired to the session that touched it, and open any change in one click. It all runs on your machine.

  • OpenCode privacy

    A session's prompts, and the files it reads, go to the provider you pick. OpenCode's free models are run by third parties that may use what you send to improve their models (see OpenCode Zen's terms), so don't use them on code you can't share.

  • Codex trust

    A local folder is marked trusted for Codex, so its .codex/ settings and AGENTS.md load, as with Claude Code. A cloned GitHub repo you didn't trust is marked untrusted, so they don't. Nothing is written to ~/.codex/config.toml.

  • Antigravity is limited

    agy can't ask for approval when run headless, so edits and most commands are turned down and listed under the reply, unless you start the session in Allow everything. No Stop, no mode or model switch mid-session, no pasted images, no slash commands and no canvas tools. See #34.

  • Limits and commits

    No agent has its own process limit: set DRAWA_MAX_LIVE if your machine needs one. In the Git window, Write with ▾ picks which agent writes commit messages and pull request descriptions.

How the permission modes map onto Codex
Ask first
Asks before edits, and before any command Codex doesn't consider safe.
Plan only
Never asks, and nothing it runs can write. It doesn't hand you a plan to approve: it answers in the chat.
Allow edits
Approves file changes inside the project only: not in .git, .codex, .agents or .claude, and not renames out of it.
Always allow
Covers a command or edit until the card's Codex process closes (after 30 idle minutes, or to stay under DRAWA_MAX_LIVE; it asks again after resuming). Drawa doesn't save Codex's permanent command rules, and canvas changes ask each time.
Changing modes
Applies from the next turn (a message sent mid-turn joins the running one), except that leaving Allow everything stops a running turn, since it can't lose full access mid-turn.

Runs on your machine, with the agent you already set up.

Drawa is one binary. It drives the claude, opencode, codex or agy CLI on your PATH with your login, settings, skills and MCP servers, and serves the page on 127.0.0.1.

  • Stays local. The server checks Host and Origin on every request, and file access stays inside the folder you opened.
  • Reach it from your phone. drawa --net prints a network link with a one-time token and a QR code.
  • No Claude subscription? Start OpenCode sessions with any provider it supports or its free models, Codex with your ChatGPT plan, or Antigravity with your Google sign-in.

The details, when you need them.

The command line, what Drawa needs, and how to configure it. The full story is in the README and INSTALL.md.

drawa
Opens the current folder at http://127.0.0.1:8765 in your browser. Press N for a new session and start typing.
drawa ~/some/project
Any other folder.
drawa --net .
Also listens on your network address, like a Vite or Next.js dev server, and prints a link with a one-time ?token= plus a QR code for your phone. --net works in any position.
drawa https://github.com/owner/repo
Clones the repo into a cache folder and opens it; reruns reuse the clone. A folder link like /tree/main/docs opens the repo on its default branch.
drawa --clean
Removes cached clones, or pass one repo's URL. Keeps any clone with uncommitted, unpushed, stashed or ignored files. Don't run it while a Drawa is open on that clone.
drawa --update
Updates to the latest release.

Trusting a repo. Opening a GitHub URL, or a folder inside its clone, asks on each launch whether to trust it. Answer n (the default) and its .claude/ settings, hooks, .mcp.json, CLAUDE.md, OpenCode project config, and Codex's .codex/ and AGENTS.md are ignored, since they could run commands on your machine.

In the message box, / opens skills and slash commands and @ references files or canvas items. The toolbar picks the model and the permission mode.

Drawa is built to run locally, for one user.

  • Localhost only. The server listens on 127.0.0.1 unless you pass --net, and checks the Host header on every request either way.
  • A token for the network. With --net, the network address also needs its one-time ?token=, checked once, then kept in a cookie and dropped from the address. Five wrong guesses lock that address out for a few minutes. Treat the link like a password, and only use --net on a network you trust.
  • Same-origin changes. Any request that changes something must come from Drawa's own page, with a matching Origin.
  • Confined files. File access stays inside the project folder you opened.
  • Per-process tool tokens. Claude's canvas tools use a token per process, so only that session's own claude can call them.
