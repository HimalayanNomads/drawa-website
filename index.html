Four colors, and each one means something.

Everything else on the canvas stays neutral, so what Claude did is readable from across the room.

  1. ReadFiles Claude opened to understand the problem. Dotted, because nothing changed.
  2. EditFiles it changed. Click one for the diff, from every session that touched it.
  3. WriteFiles it created from nothing, like the test that proves the fix.
  4. RunCommands it ran, collected beside the card with their output.

Sub-agents in the open

Every sub-agent gets a window of its own that fills in as it works, and you can message it directly.

Claude uses the canvas too

Built-in tools let Claude read, create, edit and link canvas items: a diagram of the flow it traced, a note on what's left. Changes go through the usual approval.

A whiteboard around your code

Sticky notes, a Markdown scratchpad, Mermaid diagrams, pictures, pinned snippets and freehand ink. @-mention any of them in a message, or drop one on a card.

Git and GitHub built in

Browse status and history, commit and push. Open pull requests and issues through gh, and send a PR, its failing checks or its reviews straight to Claude.

Picks up where you left off

Resume past sessions from history. The layout survives a reload, and a reload re-attaches to sessions that are still running.

Runs on your machine, with the Claude you already set up.

Drawa is one binary. It drives the claude CLI on your PATH with your login, settings, skills and MCP servers, and serves the page on 127.0.0.1.

  • Stays local. The server checks Host and Origin on every request, and file access stays inside the folder you opened.
  • Reach it from your phone. drawa --net prints a network link with a one-time token and a QR code.
  • No Claude subscription? Start OpenCode sessions instead, with any provider it supports or its free models.

Install it in one line.

Downloads the release binary for your OS to ~/.local/bin/drawa. No Go or Node needed. Update later with drawa --update.

$ curl -fsSL https://raw.githubusercontent.com/probablysamir/drawa/main/install.sh | sh
  1. Open a projectcd ~/my/project && drawa
  2. Start a sessionpress N and type

Needs Claude Code or OpenCode on your PATH. git and gh are optional. macOS or Linux; Windows isn't supported yet. Manual downloads and building from source.
